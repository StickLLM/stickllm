Drives

StickLLM never partitions or formats your own drives. To prepare one, use your computer's disk tools.

Pick an existing drive or partition, then a folder. The vault is created as a file inside it. Encrypted host volumes (BitLocker, LUKS) are never opened. Unlock them in the host OS first.
