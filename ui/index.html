Drives

    
    
    
  

  

  

  
StickLLM never partitions or formats your own drives. To prepare one, use your computer's disk tools.

  
Pick an existing drive or partition, then a folder. The vault is created as a file inside it. Encrypted host volumes (BitLocker, LUKS) are never opened — unlock them in the host OS first. Vault and model files are detected automatically in the folder picker.


  
Vault location

  
Open an existing vaultBrowse to a stickllm-vault.img. Vault files are detected automatically.
