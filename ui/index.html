How to load a model

        

          No model loads at boot. Open Models → radio select a model →
          set the context slider → Activate.
        

        
How to connect

        

          Open the URL on the same LAN and click Pair to mint a new code
          (unpairs old browsers). The stick/kiosk chat shows New PAIR CODE;
          enter it here. Loopback on the stick needs no pair.
